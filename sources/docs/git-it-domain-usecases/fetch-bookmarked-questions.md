# FetchBookmarkedQuestions

## 목적
사용자가 북마크한 문제 목록을 조회한다.

## 역할
서버에 저장된 북마크 상태를 기준으로 저장한 문제 목록을 반환한다.

## 책임
- 사용자의 북마크 문제 목록을 서버에서 조회한다.
- 필요한 경우 Project ID를 조회 조건으로 사용한다.
- 북마크된 문제 정보를 반환한다.

## 입력
- Project ID (선택)

## 출력
- 북마크 문제 목록

## 제외 책임
- 개별 문제의 북마크 상태 변경
- 북마크 목록 로컬 캐싱
- 프로젝트별 필터 UI 상태 관리

# FetchLearningProjects

## 목적
사용자가 학습할 수 있는 학습 프로젝트 목록을 조회한다.

## 역할
서버에 저장된 사용자의 학습 프로젝트를 페이지 단위로 조회하여 목록 화면에 필요한 정보를 반환한다.

## 책임
- 학습 프로젝트 목록을 서버에서 조회한다.
- 요청한 페이지와 크기를 조회 조건으로 전달한다.
- 프로젝트별 진행 정보와 다음 학습 정보를 반환한다.
- 다음 페이지 존재 여부를 반환한다.

## 입력
- Page
- Size

## 출력
- 학습 프로젝트 목록
- 다음 페이지 존재 여부

## 제외 책임
- 목록 UI 상태 관리
- 무한 스크롤 이벤트 감지
- 프로젝트 목록 로컬 캐싱
- 프로젝트 생성 상태 감시

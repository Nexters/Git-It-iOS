# FetchLearningSet

## 목적
특정 학습 세트의 문제와 현재 풀이 상태를 조회한다.

## 역할
서버에 저장된 문제 및 기존 답변 상태를 기준으로 사용자가 이어서 학습할 수 있는 세트 정보를 반환한다.

## 책임
- Project ID와 Set ID를 기준으로 학습 세트를 조회한다.
- 세트에 포함된 문제 목록을 반환한다.
- 이미 풀이한 문제의 기존 답변 상태를 함께 반환한다.
- 서버 응답을 기준으로 현재 학습 가능한 상태를 구성할 수 있도록 한다.

## 입력
- Project ID
- Set ID

## 출력
- Learning Set
- 문제 목록
- 기존 답변 상태

## 제외 책임
- 풀이 진행 상태의 로컬 저장
- 이어 풀 위치의 별도 영속화
- 문제 답변 제출
- 화면 내 문제 이동 상태 관리

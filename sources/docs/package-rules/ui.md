# UI 패키지 규칙

**상태**: 초안

**작성일**: 2026-08-07

## 설명

UI는 여러 Feature가 공유하는 시각 언어와 재사용 가능한 UI 구성요소를 담당하는 표현 경계입니다. 디자인 토큰, Typography, Color, Icon과 범용 UI Component를 제공하여 Feature가 일관된 화면을 구성할 수 있도록 합니다.

UI의 공개 API는 시각 표현과 사용자 인터랙션을 범용적인 UI 의미로 제공합니다.

## 정책

- 모든 내부 target은 공용 디자인 규칙 또는 재사용 가능한 UI 구성요소를 제공해야 합니다.
- 공개 API는 여러 Feature에서 재사용할 수 있는 범용 UI 의미로 설계해야 합니다.
- 디자인 토큰, Typography, Color, Icon과 범용 UI Component를 소유할 수 있습니다.

## 제약조건

- 프로젝트 내부의 다른 패키지에 의존해서는 안 됩니다.
- 특정 Feature의 화면, Action, 상태 또는 화면 흐름을 소유해서는 안 됩니다.
- Domain 모델이나 비즈니스 규칙을 참조해서는 안 됩니다.
- Data DTO, 서버 API 또는 데이터 접근 구현을 참조해서는 안 됩니다.
- 네트워크, 저장소 또는 Composition 로직을 구현해서는 안 됩니다.

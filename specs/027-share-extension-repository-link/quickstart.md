# 빠른 시작: 공유 시트에서 GitHub 저장소를 등록하는 Share Extension

**대상 명세**: [spec.md](./spec.md) · **계획**: [plan.md](./plan.md) · **날짜**: 2026-09-05

구현 후 이 기능이 동작하는지 확인하는 절차다. 구현 코드는 포함하지 않는다.

## 사전 준비

```sh
make tuist
```

target·scheme·entitlements 변경이 있으므로 workspace를 다시 생성해야 한다. 실행 전후 Git 상태를
비교해 추적 파일 diff가 새로 생기지 않는지 확인한다.

## 자동 검증

```sh
project_build_runner=$(./tools/repository-paths/bin/repository-paths.sh GIT_IT_PROJECT_BUILD_RUNNER)
"$project_build_runner" build
"$project_build_runner" compile
"$project_build_runner" test
```

세 명령은 순차 실행을 전제로 `sources/DerivedData/PreCommit`을 공유한다. 기대 결과는 다음과
같다.

| 검증 | 기대 결과 |
|---|---|
| `build` | 새 Extension target을 포함한 모든 공유 scheme이 Debug로 빌드된다 |
| `compile` | 테스트 scheme의 build-for-testing이 성공한다 |
| `test` | 신규 단위 테스트를 포함해 모든 테스트가 통과한다 |

셸 스크립트를 바꾸지 않았다면 스크립트 검증은 실행하지 않아도 된다.

## 수동 검증(실기기 필요)

Keychain access group, App Group, 공유 시트 노출은 Simulator만으로 충분히 확인되지 않는다.

1. **진입 노출**: Safari에서 GitHub 저장소 페이지를 열고 공유 시트에 Git-It이 보이는지 확인한다.
   텍스트만 공유했을 때 노출되지 않는지도 확인한다. (FR-001)
2. **정상 등록**: 로그인 상태에서 저장소를 공유해 조회 결과와 난이도 선택지가 뜨는지, 등록 후
   성공 표시와 호스트 앱 복귀가 되는지 확인한다. (시나리오 1, FR-024)
3. **본 앱 반영**: 본 앱을 백그라운드에 둔 채 등록한 뒤 앱으로 복귀해 추가 화면 이동 없이 목록에
   나타나는지, 난이도가 선택값과 같은지 확인한다. (SC-005, FR-028)
4. **URL 오류**: GitHub 사용자 프로필과 GitHub 외 URL을 공유해 오류 안내가 뜨고 등록이 차단되는지
   확인한다. (FR-004)
5. **로그인 필요**: 로그아웃 후 공유해 로그인 안내가 뜨는지, 이때 갱신 요청이 발생하지 않는지
   확인한다. (FR-008, SC-004)
6. **앱 실행 필요**: 이전 버전에서 로그인한 기기에 새 버전을 설치하고 본 앱을 실행하기 전에
   공유해 "앱 실행 필요" 안내가 뜨는지, 본 앱을 한 번 실행한 뒤에는 재로그인 없이 등록되는지
   확인한다. (FR-011a, SC-008)
7. **리마인더**: 알림 권한 허용 상태에서 등록하고 생성 완료 시 알림이 오는지 확인한다. 권한
   미결정 상태에서 등록할 때 권한 요청 프롬프트가 뜨지 않는지도 확인한다. (SC-006a)
8. **실패와 재시도**: 기내 모드에서 등록해 실패 상태와 재시도를 확인하고, 이미 등록된 저장소를
   공유해 서버 사유가 표시되는지 확인한다. (시나리오 3)
9. **중단**: 요청 중 화면을 닫고 재진입해 자동 재실행이 없는지 확인한다. (SC-006)
10. **자원**: Xcode Debug Navigator 또는 Instruments로 Extension 최대 메모리를 측정해 종료 없이
    완주하는지 확인한다. 관측한 최대치를 PR에 기록한다. (SC-007)
10a. **응답 시간**: 기내 모드에서 비저장소 URL과 로그아웃 상태를 각각 공유해, 공유 시트 선택부터
    오류·로그인 안내가 보일 때까지 1초 이내인지 확인한다. 이어서 정상 네트워크에서 같은 저장소를
    Extension과 본 앱 저장소 확인 화면으로 각각 3회 측정해 등록 가능 상태 도달 시간을 비교하고 두
    측정값을 PR에 기록한다. (SC-002, SC-002a)
11. **진단 로그**: Console.app에서 subsystem `com.nexters.hytime.gitit`, category `ShareExtension`
    로그가 실패 경로별로 구분되는지, 토큰·개인정보가 없는지 확인한다. (SC-010)

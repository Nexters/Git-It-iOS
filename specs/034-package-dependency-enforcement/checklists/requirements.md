## 검증 메모

- `tools/` 아래 `bin/` `core/` `config/` `tests/` 구조, POSIX 셸, pre-commit 단계와 CI 게이트
  등록 위치는 리뷰 문서 FR-4·FR-5가 지정한 고정 제약이라 명세에 남겼다. 설정 파일 형식과
  파싱 방법은 계획 단계로 넘겼다.
- 리뷰 문서는 모듈의 소속 패키지를 따로 정하지 않았다. 실측 결과 `GitIt`,
  `ShareExtension`, `DesignSystem`, `notoSansKR`, `plusJakartaSans`는 패키지 접두어가 없어,
  소속을 `<패키지>ModuleName.swift` 선언 파일로 판별한다는 가정과 경계 사례를 더했다.
- 리뷰 문서 FR-3의 "manifest에 없는 import도 위반"은 패키지 조합 검사로는 잡히지 않는다.
  target 선언 단위 검사로 FR-005에 분리했다.
- `CompositionAdapter` 의존 모듈 수 12는 리뷰 문서 근거 시점과 현재(`a9021ec`)가 같다.
  명세 032·033은 이 target의 의존 목록을 바꾸지 않았다.
- `ExternalRepository`와 생성 리마인드 조립을 어느 도메인 축에 둘지는 리뷰 문서가 정하지
  않았다. 6개 이하 제약 안에서 계획 단계가 결정하도록 가정에 남겼다.

## 참고

- `APNs`, `content-available`은 사용자가 지정한 계기와 플랫폼 제약이라 가정 섹션에 원문으로 남겼다.
- "APNs 알림 수신"의 범위(모든 원격 알림)는 합리적 기본값으로 가정에 기록했다. 생성 결과 알림으로 한정하려면 `/speckit-clarify`에서 조정한다.
- 2026-09-27 045 병합 후 재검증했다. 모든 항목이 통과한다.
- 배경의 "구현 현황" 표와 요구사항의 "구현됨" 표기는 병합 요청이 명시한 진행 상태 기록이며, 요구사항 문장 자체는 결과 중심으로 유지했다. 커밋 해시는 추적용 참조다.
- 045 FR-007은 전제(목록 제외 필터) 제거로 폐기 사유와 함께 기록했다. 045 요구사항은 FR-009~FR-022로 재번호하고 원 식별자를 괄호로 남겼다.
- 2026-09-28 알림 누락 뒤 앱 아이콘 복귀 복구(시나리오 8, FR-023~FR-026, SC-016~SC-018)를 추가한 뒤 재검증했다. 목록 포함을 완료로 보는 근거는 사용자 확인(서버가 완료를 목록에 먼저 반영)이며 가정과 시나리오 7에서 검증하도록 기록했다. 모든 항목이 통과한다.
- 2026-09-28 FR-026·SC-017을 폐기했다. 목록 포함을 완료로 보는 판정이 생성 중 목록 갱신 때 리마인드 대상을 지워 포그라운드 로컬 알림이 울리지 않았다. 시나리오 8, 시나리오 7-5, 예외·경계 사례, 가정에서 목록 근거를 제거했다. 재검증 중 SC-018의 전제가 목록 경로 없이는 성립하지 않고 시나리오 8의 우선순위 이유가 남은 한계를 드러내지 않는 문제를 발견해, SC-018 전제에 알림 센터 결과 알림 잔존을 추가하고 알림을 지웠거나 권한이 꺼진 경우의 한계를 명시했다. 수정 후 요구사항 완전성(검증 가능성, 측정 가능한 성공 기준, 수용 시나리오, 예외·경계 사례, 가정)과 기능 준비 상태 항목을 다시 확인했고 모든 항목이 통과한다.
- 미완료 항목은 `/speckit-clarify` 또는 `/speckit-plan` 전에 명세를 보완해야 한다

# 화면 목록과 그룹 분할 정의

**대상 기능**: `006-final-uxui-screens` · **조사일**: 2026-08-19

**원천**: Figma `mCRt0ejmzI4EFW3UnC9Bzb` › 페이지 `📌 서비스 설계`(`86:761`) ›
섹션 `최종 UXUI`(`720:8655`)

이 문서는 FR-001, FR-002, FR-019, FR-028의 산출물이다. `최종 UXUI` 섹션 하위를 재귀
조회해 기기 크기 프레임 65개를 확정했고, 각 프레임을 정확히 하나의 그룹 또는 제외
항목에 배정했다.

이 계약은 전체 프레임의 목록·그룹·분류 상태까지만 확정한다. 참조 화면의 구현 위치·구현
상태·상태별 근거와 상세 여백·간격·색은
[참조 화면 레이아웃·상호작용 계약](./reference-screen-layout.md)이 소유하며, 나머지 화면의
상세 계약은 `내용 미대조`를 해소하는 G1~G5 후속 기능이 소유한다.

## 조회 방법

`section.children`만으로는 프레임을 모두 찾을 수 없다. 섹션의 직계 자식 70개 중 기기
크기 프레임은 28개뿐이고 나머지는 `Group 2147207205`, `Group 2147207206`,
`Group 2147207207`, `Group 2147207208`, `Group 2147207209` 안에 중첩되어 있다. 재귀
탐색으로 `type ∈ {FRAME, COMPONENT}`이면서 `width ≥ 320`, `height ≥ 700`인 노드를
수집했다.

**제외한 조회 결과**: `홈화면 (완)`(`1828:19279`, 700×840)은 카드 6장과 `불러오기`
프레임을 나열한 설명용 조합이며 기기 크기 화면이 아니다.

## 완료 조건

- 프레임 65개가 정확히 하나의 그룹 또는 제외 항목에 있다.
- 상태 변형 수가 "내용 미대조"로 표시된 항목은 담당 그룹 기능이 대조해 확정한다.
- 전환 표의 모든 행 100%가 `확정` 또는 `추정` 근거 수준을 가지며, 추정 전환을 확정으로
  기록한 건수가 0건이다(SC-022).
- 그룹마다 시작 화면이 정확히 하나 있고 소유 컴포넌트가 다른 그룹과 겹치지 않는다.

06

SwiftUI 표현

§01의 변수를 코드에서 쓰는 방식입니다. GeometryReader로 폭을 읽어 계산하지 않고, maxWidth: .infinity와 padding으로 같은 결과를 얻습니다. 값을 직접 계산해야 하는 곳(스크림 높이, 시트 최대 높이)만 LayoutMetrics를 씁니다.

// 1. 폭 — 콘텍스트에서 파생. 숫자를 박지 않는다 VStack(spacing: LayoutToken.gutter.cgFloatValue) { … } .frame(maxWidth: .infinity) // contentWidth 335–400 .padding(.horizontal, LayoutToken.margin.cgFloatValue) // 2열 카드 — 161.5–194 LazyVGrid(columns: [GridItem(.flexible()), GridItem(.flexible())], spacing: LayoutToken.gutter.cgFloatValue) { … } // 3열 통계 카드 — 103.67–125.33 HStack(spacing: LayoutToken.gutter.cgFloatValue) { ForEach(stats) { StatCard($0).frame(maxWidth: .infinity) } } // 가로 스크롤 카드 — 폭 고정 154, 잘림 허용 ScrollView(.horizontal, showsIndicators: false) { HStack(spacing: LayoutToken.gutter.cgFloatValue) { ForEach(repos) { RepositoryCard($0).frame(width: 154) } } .padding(.horizontal, LayoutToken.margin.cgFloatValue) }
// 2. 세로 — safe area는 읽고, 높이는 고정 struct LayoutMetrics { let safeTop: CGFloat // 20 – 68 let safeBottom: CGFloat // 0 – 34 let header: ScreenHeader.Style var topScrimHeight: CGFloat { safeTop + header.height } var bottomScrimHeight: CGFloat { safeBottom + (hasTabBar ? 93 : 0) } var tabShellInset: CGFloat { max(safeBottom, 24) + 68 } } ScrollView { LazyVStack(spacing: LayoutToken.gutter.cgFloatValue) { … } .padding(.horizontal, LayoutToken.margin.cgFloatValue) } .safeAreaInset(edge: .top) { ScreenHeader(style) } // 50/64/98/120 .safeAreaInset(edge: .bottom) { Color.clear.frame(height: metrics.tabShellInset) } .overlay(alignment: .bottom) { TabShell(selection) } // 시트 — 비율을 박지 않고 콘텐츠 높이, 상한만 둔다 .sheet(isPresented: $show) { SheetContent() .presentationDetents([.height(min(contentHeight, screenHeight - safeTop - 16))]) }
.frame(width:)를 쓰는 곳은 넷뿐 — RepositoryCard(154), 썸네일(52·80·99), 애니메이션(128·200), 아이콘 버튼(40). 나머지 모든 폭은 부모에서 파생됩니다. 텍스트는 .frame(maxWidth: .infinity, alignment:)로 콘텍스트 폭을 채우고 줄 수 제한은 가이드 §4의 Text Style 규칙을 따릅니다.

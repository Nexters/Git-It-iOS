UI·UX 가이드와 레이아웃 규격

디자인 시스템 규격 문서가 무엇이 어떤 값인지를 정의한다면, 이 문서는 그 값을 어떻게 배치하고 어떻게 반응시키는지를 정의합니다. 값은 Figma 파일 실측에서 가져오되, 치수는 실기기 기준으로 다시 계산했습니다. 파일의 360 × 800 캔버스는 어떤 iPhone과도 일치하지 않으므로 규격에서는 쓰지 않습니다.

01

레이아웃 기본

파일은 360pt 폭에 그려져 있고 카드·행·문항이 모두 320입니다. 이 320은 360 − 20 × 2의 결과값이므로, 규격에서는 320을 옮기지 않고 좌우 여백 20만 옮깁니다. 실기기에서 콘텐츠 폭은 335(SE)부터 400(17 Pro Max)까지 달라집니다.

04

타이포 적용

타이포는 값을 옮기는 것만으로 끝나지 않습니다. Figma는 행간을 행 박스 높이로, SwiftUI는 행 사이 간격으로 다루기 때문에 환산이 필요하고, 이 차이를 방치하면 모든 카드 높이가 어긋납니다.

4.1 행간 환산

목표 행 높이 = size × lineHeightPercent / 100 lineSpacing = 목표 행 높이 − UIFont.lineHeight 상하 보정 = lineSpacing / 2 // 첫 행 위, 마지막 행 아래를 Figma와 맞춤 extension View { func designSystemLineSpacing(_ token: TextStyleToken) -> some View { let target = token.size * token.lineHeightPercent / 100 let natural = UIFont(name: token.postScriptName, size: token.size)!.lineHeight let spacing = max(0, target - natural) return lineSpacing(spacing).padding(.vertical, spacing / 2) } }

UIFont.lineHeight는 번들된 폰트 파일의 메트릭에 따라 결정되므로 상수로 적지 않고 런타임에 읽습니다. 아래 표의 목표 행 높이만 규격이며, 이 값을 만족하면 Figma와 같은 높이가 나옵니다.

Pressing은 배경색을 바꾸는 것이 아니라 기존 표면 위에 white30을 겹칩니다. Primary·Secondary·Text 모두 같은 방식이므로 스타일별 누름 색을 따로 정의하지 않고 한 ButtonStyle에서 처리합니다.

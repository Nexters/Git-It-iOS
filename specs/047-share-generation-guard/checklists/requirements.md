## 참고

- FR-008·FR-009의 `ProjectGenerationState` 재사용과 공유 확장 Feature 안의 단순화된 UseCase 경계는 사용자가 명시한 고정 제약이라 원문으로 남겼다. 경계의 이름, 선언 위치(파일·target), 구현·조립 위치는 계획 단계에서 정한다.
- 시나리오 2는 개발자를 행위자로 한 내부 검증 시나리오다. 최종 사용자 가치를 꾸며내지 않고 판정 기준 일치와 테스트 경계를 검증 결과로 둔다.
- 판정 순서(URL → 로그인 → 생성 진행 → 조회), 생성 기록 읽기 실패 시 허용, 관찰 없이 판정 시점마다 한 번 읽기는 합리적 기본값으로 예외·경계 사례와 가정에 기록했다.

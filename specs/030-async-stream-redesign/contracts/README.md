# 계약: 생성 상태 관측 단일화와 무효 스트림 제거

**날짜**: 2026-09-15 | **명세**: [spec.md](../spec.md) | **데이터 모델**: [data-model.md](../data-model.md)

이 문서는 패키지 경계를 넘는 공개 계약의 **변경**만 기술한다. 구체 타입 선언과 파일 경로는 `tasks.md`가 소유한다.

## 1. 추가하는 계약

### 1.1 생성 추적 (Domain UseCase 계약)

App이 Feature에 주입하는 실행 가능한 의존성이다. 상태 수명과 동시성 제어를 함께 소유하므로 다중 연산 계약으로 둔다.

| 연산 | 입력 | 출력 | 동작 |
| --- | --- | --- | --- |
| 생성 시작 | 저장소 URL, 요청 시각 | 시작 성공 여부 | 같은 정규화 URL의 진행 중 기록이 있으면 실패를 반환한다 |
| 프로젝트 식별자 연결 | 프로젝트 식별자, 저장소 URL | 없음 | 해당 진행 중 기록에 식별자를 채운다 |
| 생성 종료 | 저장소 URL 또는 프로젝트 식별자 | 없음 | 해당 기록을 제거한다 |
| 현재 상태 조회 | 없음 | 생성 상태 | 만료 정리 후의 스냅샷 |
| 상태 관측 | 없음 | 생성 상태의 연속 전달 | **첫 값으로 현재 상태를 전달한 뒤** 이후 변경을 전달한다 |

**보장**

- 관측 시작 순서와 무관하게 같은 시점의 관측자는 같은 상태를 얻는다.
- 관측 종료 시 내부 관측자 목록에서 제거된다.
- 여러 관측자가 동시에 존재할 수 있으며 모두 같은 값을 받는다.

### 1.2 자격 증명 확인 (Domain UseCase 계약)

| 연산 | 입력 | 출력 | 동작 |
| --- | --- | --- | --- |
| 자격 증명 확인 | 없음 | 자격 증명 상태 | 재인증 필요일 때만 저장된 세션과 자격 증명 정보를 정리한다 |

**보장**

- 일시적 확인 불가일 때 세션을 정리하지 않는다.
- 세션 정리 실패는 반환 값을 바꾸지 않는다.

### 1.3 생성 상태 보존 (Domain 계약, Data가 구현)

| 연산 | 입력 | 출력 |
| --- | --- | --- |
| 불러오기 | 없음 | 생성 상태 |
| 저장 | 생성 상태 | 없음 |

기존 키에서 새 키로의 1회 이관은 이 계약의 구현이 수행한다. 호출자는 이관을 알지 못한다.

## 2. 제거하는 계약

| 계약 | 소유 | 제거 이유 |
| --- | --- | --- |
| 자격 증명 변경 관측 | Domain 인증 저장소 계약 | 프로덕션에서 값을 전달하는 진입점이 없다 (FR-005) |
| 인증 결과 관측 UseCase | Domain | 위 계약에 의존하며 동작하지 않는다 |
| 생성 결과 관측 UseCase | Domain | 저장소 호출을 그대로 반환하는 위임 계층이다 (FR-012) |
| 진행 정보 추적 UseCase | Domain | 생성 추적 계약으로 흡수 |
| 등록 상태 저장소 계약 | Domain | 생성 추적 계약과 생성 상태 보존 계약으로 흡수 |
| 진행 정보 저장소 계약 | Domain | 생성 상태 보존 계약으로 흡수 |
| 자격 증명 변경 전달 | Infrastructure Apple 인증 제공자 | 위 계약 제거에 따라 불필요 |

## 3. 변경하는 계약

| 계약 | 변경 |
| --- | --- |
| 기기 토큰 갱신 통지 (Composition → App) | 값 없는 연속 전달에서 갱신 시 호출되는 통지 수단으로 바꾸고, 기본값 없는 필수 의존성으로 만든다 |
| 프로젝트 생성 UseCase | 등록 상태 저장소 대신 생성 추적을 사용한다. 외부 시그니처는 유지한다 |
| 프로젝트 목록 조회 UseCase | 등록 상태 저장소 대신 생성 추적을 사용한다. 외부 시그니처는 유지한다 |
| Feature 초기화 인자 | 생성 결과 관측과 진행 정보 추적 자리에 생성 추적을 받는다 |

## 4. 유지하는 계약

- 생성 결과 수신 저장소 계약 (푸시 통지 → Domain 값). 생성 추적의 내부 입력으로만 사용한다.
- 푸시 페이로드 스키마. 변경하지 않는다.
- 대기 시간 정책과 보존 한도 값.

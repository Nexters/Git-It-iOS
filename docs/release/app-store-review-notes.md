# App Store 심사 노트

App Store Connect의 **App Review Information > Notes**에 붙여넣을 내용과 그 근거를 정리합니다.
심사자가 앱의 핵심 기능을 재현하지 못하면 지침 2.1(App Completeness)로 리젝되므로,
아래 정보는 제출할 때마다 최신 상태로 유지합니다.

## 왜 노트가 필요한가

| 사실 | 근거 | 노트에 반드시 넣을 내용 |
| --- | --- | --- |
| 앱은 GitHub 저장소 URL 없이는 아무 기능도 쓸 수 없다 | `RepositoryLinkInputFeature`가 등록 플로의 시작점 | 심사자가 쓸 공개 저장소 URL |
| 퀴즈 생성에 **최소 5분** 걸린다 | `GenerationWaitPolicy.standard.minimumWait = 300` | 대기 시간과 완료 알림 동작 |
| 로그인은 Apple로 로그인 전용이다 | `GitIt.entitlements`의 `com.apple.developer.applesignin` | 별도 데모 계정이 없다는 설명 |
| 퀴즈 완료를 푸시로 알린다 | `UIBackgroundModes: remote-notification` + `FirebaseMessagingAppDelegate` | 알림 권한의 사용 목적 |
| 계정 삭제는 앱 안에서 즉시 처리된다 | `SettingsScreen+AccountDeletionView` | 지침 5.1.1(v) 충족 경로 |

## 붙여넣을 노트 (영문)

```text
ABOUT THE APP
Git It turns a public GitHub repository into a personalized quiz set so developers can
review what they have actually built. All quiz content is generated by AI from the
source repository.

SIGN IN
The app uses Sign in with Apple exclusively. There is no username/password account, so
no demo credentials are required — please sign in with your own Apple ID. Account
creation happens automatically on first sign-in.

HOW TO REVIEW THE MAIN FEATURE
1. Sign in with Apple, accept the two required policy documents, and complete the short
   onboarding (job position and career level).
2. Tap "+" on the Home tab to register a project.
3. Paste this public repository URL:
       <<여기에 공개 저장소 URL을 넣으세요>>
4. Choose a quiz difficulty and start generation.

IMPORTANT — GENERATION TAKES AT LEAST 5 MINUTES
Quiz generation runs on our server and is intentionally rate-limited. The progress
screen will stay visible for a minimum of 5 minutes. This is expected behavior, not a
hang. You may leave the app; if you allow notifications, a local notification tells you
when the set is ready. Generated sets also appear on the Projects tab.

ALREADY-PREPARED ACCOUNT (optional, faster review)
If you prefer to skip the wait, sign in with the Apple ID below, which already has
generated quiz sets:
       <<사전 생성된 계정을 쓰려면 Apple ID를 넣고, 아니면 이 문단을 삭제하세요>>

PUSH NOTIFICATIONS
Notifications are used only to tell the user that their quiz set finished generating.
The app is fully usable if notification permission is denied.

SHARE EXTENSION
From Safari or the GitHub app, share a repository URL and choose "Git It" to register
that repository without leaving the current app.

ACCOUNT DELETION
Settings tab > "계정 삭제" (Delete Account). Deletion is immediate and removes the
account and its generated content.

DATA COLLECTION
We collect the email address and name provided by Sign in with Apple, plus a device
identifier and push token used solely to deliver the completion notification. No
tracking, no third-party advertising, no IDFA.
```

## 제출 전 확인 목록

- [ ] 위 노트의 `<<...>>` 자리를 실제 값으로 채웠다
- [ ] 넣은 저장소 URL로 생성이 끝까지 성공하는 것을 직접 확인했다
- [ ] App Store Connect의 앱 개인정보 라벨이
      [PrivacyInfo.xcprivacy](../../sources/Projects/App/GitIt/Resources/PrivacyInfo.xcprivacy)의
      선언(이메일·이름·기기 ID)과 일치한다
- [ ] TestFlight 빌드에서 실제 푸시 수신을 확인했다 (`APS_ENVIRONMENT`가 production으로 나가는지)
- [ ] 개인정보 처리방침·이용약관 URL이 열린다
      ([policy-manifest.json](../../sources/Projects/App/GitIt/Resources/Policies/policy-manifest.json))
- [ ] 스크린샷이 6.9"/6.5" iPhone 규격이다 (앱은 iPhone 전용으로 제출)

## AI 생성 콘텐츠에 대한 참고

퀴즈와 해설은 AI가 생성합니다. 화면에는 "AI 해설"로 표기하고 있지만, 부적절한 콘텐츠를
사용자가 신고할 수단은 아직 없습니다. 지침 1.2(사용자 생성 콘텐츠)로 문의를 받으면
신고 경로 추가가 필요합니다.

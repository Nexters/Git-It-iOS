# 접두어와 접미어

[Git It iOS 네이밍 컨벤션](../naming.md)의 규칙 문서입니다.

접두어·접미어는 다음 질문에 모두 답할 수 있을 때 사용합니다.

1. 어떤 책임, 방향, 수명 또는 경계를 구분하는가?
2. 제거하면 어떤 실제 충돌이나 오해가 생기는가?
3. 선언의 모든 연산과 상태가 그 수식어의 의미를 충족하는가?

허용할 수 있는 예는 실제 wire 경계를 표현하는 `RequestDTO`·`ResponseDTO`, 저장 수명을 구분하는 `Stored...`, 책임을
충족하는 `...Repository`·`...Storage`입니다. 다만 같은 접미어라도 역할이 맞지 않으면 사용할 수 없습니다.

다음 목적의 일괄 적용은 허용하지 않습니다.

- 같은 feature 또는 target 소속임을 표시하기 위한 공통 접두어
- 이름 길이와 모양을 맞추기 위한 공통 접미어
- 현재 책임이 아닌 향후 가능성을 나타내기 위한 `Manager`, `Service`, `Handler`
- 패키지 이름을 반복하는 `Domain...`, `Data...`, `Infrastructure...` 접두어

# 경계를 넘는 값

[Git It iOS 네이밍 컨벤션](../naming.md)의 규칙 문서입니다.

저장되거나 반환·전달되어 원래 선언 문맥을 잃는 값은 이름만으로 목적을 재구성할 수 있어야 합니다.

- 서로 다른 발급 주체의 식별자가 공존하면 구분에 필요한 발급 주체 또는 소유 경계를 드러냅니다.
- 현재 값과 갱신 값, 일회성 값과 장기 저장 값처럼 수명이 의미를 바꾸면 그 차이를 드러냅니다.
- `id`, `reference`, `value`, `token`, `state`처럼 단독으로는 의미가 넓은 이름은 경계를 넘을 때 무엇의 값인지 검토합니다.
- 메서드와 타입이 목적을 명확히 제공하는 짧은 지역 매개변수에서는 같은 수식어를 반복하지 않을 수 있습니다.
- 비밀 값은 이름뿐 아니라 타입, 노출 범위와 문자열 표현 정책으로도 보호합니다. 보안 책임을 이름만으로 충족했다고 판단하지 않습니다.

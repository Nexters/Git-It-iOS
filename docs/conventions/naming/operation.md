# 연산

[Git It iOS 네이밍 컨벤션](../naming.md)의 규칙 문서입니다.

- 동사와 목적어는 실제 효과와 반환 의미를 드러내야 합니다.
- `get`, `handle`, `process`, `execute`처럼 대상과 효과를 감추는 일반 동사는 더 구체적인 동사로 대체할 수 있는지 검토합니다.
- 조회, 관찰, 저장, 삭제와 취소처럼 동작과 수명에 차이가 있으면 이름에서도 구분합니다.
- 타입이나 프로토콜이 대상을 명확히 제공하면 연산명에 같은 대상을 반복하지 않을 수 있습니다.
- 비동기, 실패 가능성이나 구현 방식은 Swift 시그니처와 계약으로 충분히 표현되는 경우 이름에 중복하지 않습니다.

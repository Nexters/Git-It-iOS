# 공개 타입

[Git It iOS 네이밍 컨벤션](../naming.md)의 규칙 문서입니다.

- 타입이 소유하는 핵심 개념과 역할을 함께 식별할 수 있어야 합니다.
- 패키지 밖에서 타입 이름만 보아도 다른 동명의 개념과 구분할 수 있어야 합니다.
- 현재 소유하지 않는 역할을 암시하는 `Manager`, `Service`, `Provider` 같은 포괄 명사는 구체 책임 없이 사용하지 않습니다.
- 구현 기술이나 실행 환경은 타입의 계약 자체가 그것을 소유할 때만 포함합니다.

`LoginSession`과 일반 `Session`이 함께 존재할 수 있는 문맥에서 전자는 필요한 구분을 제공합니다. 반면 충돌 가능성이 없다는 이유만으로
모든 인증 타입에 동일한 축약 접두어를 붙이는 것은 허용 근거가 되지 않습니다.

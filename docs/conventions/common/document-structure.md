# 추상 원칙과 구체 명시의 계층

[Git It iOS 컨벤션 공통 원칙](./README.md)의 규칙 문서입니다.

컨벤션은 **추상 원칙**과 **구체 명시**를 같은 문서에 섞지 않고 계층으로 나눕니다. 규칙을
찾는 사람이 개념을 먼저 읽고 필요한 명시만 골라 읽을 수 있게 하고, 문서를 읽는 데 드는
문맥을 규칙 하나 단위로 줄이기 위한 것입니다.

## 제목 계층

- **`##`은 추상적인 개념을 다룹니다.** 그 절이 무엇을 규율하는지, 왜 그렇게 정하는지를
  서술하고 개별 판정 규칙은 담지 않습니다.
- **`###`은 그 개념에 대한 구체적인 명시를 다룹니다.** 판정 기준, 허용·금지 목록과 예시가
  여기에 옵니다.
- `##`에 딸린 `###`이 없으면 그 `##`은 개념과 명시가 분리되지 않은 것입니다. 개념을
  서술하고 명시를 `###`으로 내립니다.

## 인덱스와 참고 단위 문서

- **주제 컨벤션 파일은 인덱스입니다.** `##` 추상 원칙을 직접 서술하고, 각 `###` 아래에는
  한 줄 링크만 둡니다. 인덱스의 파일 경로와 제목은 다른 문서가 참조하는 주소이므로
  구조를 바꿀 때도 유지합니다.
- **구체 명시는 같은 이름의 하위 디렉터리에 문서 하나씩 둡니다.** 이 문서가 작업 중에
  실제로 열어 보는 참고 단위입니다.
- 참고 단위 문서는 제목, 자신이 속한 인덱스 링크, 규칙 본문만 갖습니다. `목적`,
  `적용 범위`, `검토 체크리스트`, `관련 문서`, `문서 변경 기준`은 인덱스가 소유하며 참고
  단위 문서가 다시 쓰지 않습니다.
- **검토 체크리스트는 나누지 않고 인덱스가 소유합니다.** 체크리스트는 여러 규칙을
  가로질러 검토하는 도구여서 참고 단위로 쪼개면 검토 순서가 흩어집니다.

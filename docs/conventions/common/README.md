# Git It iOS 컨벤션 공통 원칙

**상태**: 초안

**작성일**: 2026-09-13

## 목적

이 디렉터리는 `docs/conventions/`의 모든 컨벤션이 공통으로 따르는 원칙을 소유합니다.
각 주제 컨벤션은 이 원칙을 다시 서술하지 않고 링크로 참조합니다.

## 1. 문서 우선순위

컨벤션은 상위 문서가 정한 경계 안에서의 작성 방식만 소유하고, 충돌하면 컨벤션 쪽을
수정합니다.

### 1.1 상위 문서와 충돌 해소

→ [상위 문서와 충돌 해소](./document-priority.md)

## 2. 문서 구조

원칙은 추상과 구체의 두 계층으로 나누어 쓰고, 주제 문서는 인덱스와 참고 단위 문서로
분리합니다.

### 2.1 추상 원칙과 구체 명시의 계층

→ [추상 원칙과 구체 명시의 계층](./document-structure.md)

### 2.2 문서 형식과 작성 순서

→ [문서 형식과 작성 순서](./document-format.md)

## 3. 문서 간 참조

같은 규칙을 두 문서에 옮겨 적지 않고, 소유 문서를 하나 정한 뒤 다른 문서에서는 링크만
둡니다.

### 3.1 소유 문서 표기와 중복 서술 금지

## 문서 변경 기준

컨벤션 전체에 공통으로 적용하는 원칙이 추가·변경될 때 수정합니다. 특정 주제에만
적용되는 규칙은 이 디렉터리가 아니라 그 주제의 컨벤션에 둡니다.

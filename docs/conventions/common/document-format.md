# 문서 형식과 작성 순서

[Git It iOS 컨벤션 공통 원칙](./README.md)의 규칙 문서입니다.

주제 컨벤션 인덱스는 다음 순서로 작성합니다.

1. 제목과 상태·작성일·최종 수정일
2. `목적`
3. `적용 범위`
4. 주제별 세부 규칙 — `##` 추상 원칙과 그 아래 `###` 참고 단위 링크
   ([추상 원칙과 구체 명시의 계층](./document-structure.md))
5. `검토 체크리스트`
6. `관련 문서`
7. `문서 변경 기준`

규칙은 책임의 소유자와 금지 경계를 함께 밝히고, 예시는 규칙을 이해하는 데 필요한 최소
범위로 둡니다.

# 화면 골격

[Git It iOS View 컨벤션](../view.md)의 규칙 문서입니다.

화면은 UIComponent의 골격 컴포넌트로 골격을 구성하고 같은 책임을 화면에서 다시 구현하지
않습니다. 골격 책임에는 화면 배경·색 구성표·전체 영역을 맡는 화면 루트 컨테이너, 상단 좌우
아이콘 컨트롤 행, 상단 제목 텍스트, 하단 고정 액션 영역, 시트 표면, 탭 구조, 순차 흐름의 화면
스택이 있습니다.

**화면 루트는 스크롤 없는 화면 루트 컨테이너와 본문이 헤더 뒤로 스크롤하는 화면 루트 컨테이너
중 하나입니다.** 본문이 헤더·푸터 뒤로 스크롤하는 화면은 스크롤 컨테이너를, 세로 중앙 정렬처럼
스크롤하지 않는 화면은 스크롤 없는 컨테이너를 씁니다. `ScrollView` 안에서는 `Spacer`가 접히므로
중앙 정렬 화면을 스크롤 컨테이너에 담지 않습니다. 두 컨테이너를 중첩하지 않습니다.

**헤더와 푸터는 화면이 초기화 시점에 스크롤 컨테이너의 헤더·푸터 `@ViewBuilder`에서 직접
조립합니다.** 형태별로 미리 패키징한 헤더·푸터 컴포넌트는 두지 않습니다 — 화면마다 필요한
레이아웃(뒤로가기만 있는 컨트롤 바, 큰 제목이 붙은 헤더, 인라인 제목 헤더 등)이 서로 달라
하나의 계약으로 묶으면 옵션 인자만 늘어나고 화면별 실제 사용 형태를 감춥니다. 상단 아이콘
컨트롤 행 컴포넌트와 상단 제목 텍스트 컴포넌트를 화면이 원하는 대로 `HStack`/`VStack`으로
조합하고, 겹쳐 놓는 화면은 그 조합에 `.designSystemScreenMargin()`을 직접 붙입니다. 푸터도 같은
방식으로 하단 고정 액션 영역 컴포넌트에 화면 전용 콘텐츠를 담습니다.

**색 구성표는 화면 루트 컨테이너가 소유합니다.** 화면에서 `preferredColorScheme(_:)`를
다시 지정하지 않습니다. 루트 컨테이너 밖에 오버레이를 쌓아야 해서 색 구성표가 적용되지
않는 경우에는 오버레이를 컨테이너 안으로 옮기고, 구조상 불가능하면 그 이유를 코드
주석이 아니라 이 문서의 예외로 기록합니다.

**safeArea 등 실측 기기값이 필요한 컴포넌트는 각자 `GeometryReader`로 직접 측정합니다.**
공유 측정 타입을 화면과 컴포넌트 트리에 걸쳐 주입하지 않습니다.

# 분류 축은 역할입니다

[Git It iOS UIComponent 컨벤션](../ui-component.md)의 규칙 문서입니다.

컴포넌트는 **화면에서 맡는 역할**로 분류하고, 역할 이름의 폴더에 둡니다. 역할은
컴포넌트의 **공개 계약**으로 판정합니다. 구현이 다른 컴포넌트를 렌더링하는지, 파일이
몇 개인지, 어느 화면에서 처음 만들어졌는지는 판정 근거가 아닙니다.

구현 의존 구조(렌더링 트리에 다른 View를 포함하는가)로 나누던 이전 `Leaf`·`Composite`
분류는 사용하지 않습니다. 구현이 바뀌면 계약이 그대로여도 분류가 바뀌고, 호출부에
정보를 주지 못했기 때문입니다.
